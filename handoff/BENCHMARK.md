# قياس دقة التسميع: المحرك مقابل حكم المشرف

الهدف ليس نسبة الكلمات الخاطئة على القرّاء، بل: **كم خطأً حقيقيًا من أخطاء المستخدمين يكشفه النموذج، وكم مرة يُنبّه على كلمة صحيحة** — مقيسًا على تسجيلات درجات التي حكم عليها المشرف.

## 1. جهّز ملف الأحكام (judged.jsonl)

سطر واحد لكل تسجيل، من جدول أحكام المشرف في درجات:

```json
{"audio": "rec/abc.wav", "sura": 2, "aya_from": 255, "aya_to": 255,
 "mistakes": [{"type": "miss", "ref": "2:255:7"}, {"type": "sub", "ref": "2:255:9"}]}
```

- بدل `audio` يمكن وضع `text` (النص المسموع) لقياس المطابقة وحدها دون تشغيل الصوت.
- `type`: ‏`miss` متروكة · `sub` مبدّلة · `extra` زائدة · `vowel` حركة.
- `ref`: ‏سورة:آية:ترتيب الكلمة في الآية (يبدأ من ١).
- `latency_ms` (اختياري): زمن ظهور التنبيه، إن سجّلتموه.

تصدير من SQLite (عدّل أسماء الجداول والأعمدة حسب قاعدتكم):

```sql
-- مثال فقط؛ المطلوب إخراج صف JSON لكل تسجيل محكوم
SELECT json_object('audio', file, 'sura', sura, 'aya_from', aya, 'aya_to', aya,
       'mistakes', json_group_array(json_object('type', mtype, 'ref', mref)))
FROM learn_judged WHERE verdict='bad' GROUP BY file;
```

## 2. شغّل القياس

```bash
# نموذج Whisper المفتوح على الصوت
python -m engine.cli bench judged.jsonl

# على النص المسموع فقط (أسرع، بلا صوت)
python -m engine.cli bench judged.jsonl --text

# نموذجكم أنتم: صدّروا مخرجاته سطرًا سطرًا ثم مرّروها
python -m engine.cli bench judged.jsonl --pred your_model_out.jsonl
```

`--pred` ملف فيه سطر لكل تسجيل بالترتيب نفسه، كل سطر `{"mistakes":[{"type","ref"}]}` كما يراها نموذجكم. هكذا نقارن النموذجين على البيانات نفسها.

## 3. اقرأ النتيجة

| العمود | المعنى |
|---|---|
| كشف | أخطاء حقيقية وجدها النموذج (جيد) |
| فات | أخطاء حقيقية تركها (نقص) |
| خطأ | تنبيه على كلمة صحيحة (أسوأ شيء للمستخدم) |
| دقة | من كل تنبيهات النموذج، كم كانت صحيحة |
| استرجاع | من كل الأخطاء الحقيقية، كم كشف |

**القاعدة:** لرفع ثقة المستخدم، «خطأ» (التنبيه الكاذب) يجب أن يكون أقل ما يمكن، حتى لو نقص الاسترجاع قليلًا. شكوى مستخدمي Tarteel الأولى من كثرة التنبيه الكاذب.

## حدود هذه الأداة
- **Whisper لا يرى التشكيل**، فاسترجاعه لأخطاء الحركة (`vowel`) صفر بطبيعته. نموذجكم CTC هو المقياس الحقيقي لها، عبر `--pred`.
- مطابقة الكلمة بالموضع (سورة:آية:كلمة)، فاضبط ترقيم كلمات المشرف على ترقيم المصحف نفسه.
